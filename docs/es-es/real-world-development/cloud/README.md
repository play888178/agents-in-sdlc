El **[agente de GitHub Copilot en la nube](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** trabaja de forma asíncrona en la nube. Le asignas trabajo en GitHub y el agente explora el repositorio, hace cambios y abre una pull request mientras tú te ocupas de otras tareas.

En estos ejercicios añadirás instrucciones personalizadas para el agente y le asignarás una incidencia. Revisarás y usarás agentes personalizados para orientar su trabajo, supervisarás y dirigirás sesiones desde la página de agentes y, finalmente, revisarás las pull requests e iterarás sobre los resultados.

## Requisitos previos

Antes del taller, asegúrate de tener:

- [ ] Una cuenta de GitHub con un plan activo **Copilot Student, Pro, Pro+, Business o Enterprise**
- [ ] El agente de Copilot en la nube habilitado para tu cuenta u organización

> [!TIP]
> ¿No tienes un plan de pago? Los estudiantes cuya condición se haya verificado pueden obtener GitHub Copilot gratis mediante [GitHub Education][callout-student-plan-education]. El plan **Copilot Student** incluye el agente, MCP, revisión de código y Copilot CLI que se usan en este taller; permite completar todos los entornos.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> El agente en la nube está disponible en **Copilot Student, Pro, Pro+, Business y Enterprise**, es decir, en todos los planes excepto Copilot Free. En Copilot Business o Enterprise, un administrador debe habilitarlo para la organización.

> [!NOTE]
> Model Context Protocol (MCP) no se trata en este entorno. Para explorar servidores MCP con Copilot, consulta el [entorno de CLI](../cli/) o el [entorno de VS Code](../vscode/).
